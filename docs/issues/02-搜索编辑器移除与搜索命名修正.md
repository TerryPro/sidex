## 背景

Search Editor 是 VS Code 的「把搜索结果保存为编辑器」功能，属于 IDE 工作流，不适合文件浏览器产品。活动栏搜索项的悬浮标题当前显示为「搜索编辑器」，也是由 Search Editor 的 NLS key 冲突导致。

## 执行结果（2026-11-04）

| 项目 | 实际改动 |
| --- | --- |
| 目录 | `src/vs/workbench/contrib/searchEditor/` 已删除 |
| 注册 | `workbench.common.main.ts` 移除 `searchEditor` import |
| 命令与菜单 | Search Editor 的打开、序列化、命令与菜单入口全部移除 |
| 搜索引用清理 | `searchActionsFind.ts`、`searchActionsNav.ts`、`searchView.ts`、`searchWidget.ts` 中 Search Editor 分支与「Open in editor」按钮已移除 |
| NLS | 搜索视图标题恢复为「搜索」，活动栏不再串台 |
| 保留 | `search.searchEditor.*` 设置键与 `searchEditor.*` 主题颜色键保留，仅用于兼容旧配置，不影响 UI |

## 原始实施清单

- [x] 删除 `workbench.common.main.ts` 中 `searchEditor` 的 import。
- [x] 删除 `src/vs/workbench/contrib/searchEditor/` 整个目录。
- [x] 全仓搜索 `searchEditor`、`SearchEditor`、`openSearchEditor`、`OpenNewSearchEditor`，清理 UI、命令与代码引用。
- [x] 检查 `src/vs/workbench/api` 中 Search Editor 相关编辑器类型并同步删除。
- [x] 修正 NLS key，搜索视图文案恢复为「搜索」。
- [x] 确认 `Ctrl+Shift+F` 仍打开搜索面板。

> 说明：设置键与主题色键不属于 UI/命令入口，保留以避免旧配置报未知键。
