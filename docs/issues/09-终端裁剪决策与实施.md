## 背景

终端是完整的专业 IDE 能力，包含 xterm、shell 集成、配置档案、任务联动、大量设置项。产品定位是「文件浏览 + 编辑器」，终端不是主链路。

## 决策

采用**方案 B：基础终端**。保留新建、切换、关闭、复制粘贴、清屏等基础能力，移除 IDE 子特性注册。

## 执行结果（2026-11-04）

| 项目 | 实际改动 |
| --- | --- |
| 终端注册 | `contrib/terminal/terminal.all.ts` 仅保留 `terminal.contribution`、环境变量、扩展点、终端视图、无障碍与查找 |
| 子特性 | 自动回复、命令指南、链接、通知、缩放、粘性滚动、快速访问、快速修复、typeAhead、发送序列、建议、WSL 推荐等不再 import |
| 目录 | `contrib/terminalContrib/` 目录保留但未被引用，不进入打包产物 |
| Rust | `crates/sidex-terminal`、`commands/terminal.rs`、`process.rs` 保留，基础终端可执行 |
| 原生菜单 | 只保留基础终端入口，移除拆分终端菜单 |
| 设置 | 保留基础 `terminal.integrated.*` 默认值 |
