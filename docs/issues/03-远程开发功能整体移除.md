## 背景

远程开发（SSH、WSL、容器、Codespaces、Remote Tunnels）是专业 IDE 能力，需要网络、凭证与远程运行时，与「本地文件浏览 + 编辑器」定位不符。

## 执行结果（2026-11-04）

| 项目 | 实际改动 |
| --- | --- |
| 远程 UI | `src/vs/workbench/contrib/remote/` 已删除，`workbench.common.main.ts` 移除 import |
| Rust 命令 | `src-tauri/src/commands/remote.rs` 已删除，`commands/mod.rs` 与 `lib.rs` 移除 `remote_*` 注册与退出清理 |
| Rust crate | `crates/sidex-remote/` 已删除，根 `Cargo.toml` 与 `src-tauri/Cargo.toml` 依赖已清理 |
| 前端服务 | `workbench.web.main.ts` 移除远程入口；`sidexRemoteService.ts` 保留为 null/兼容实现，由 `nullRemoteAgentService` 引用 |
| 架构空服务 | `nullRemoteAgentService`、`IRemoteExplorerService` 空实现保留，避免依赖注入失败 |
| 文案 | `nls-loader.ts` 中远程/Codespace 文案保留为未引用词条，不影响命令面板 |

## 原始实施清单

- [x] 删除 `workbench.common.main.ts` 中 `remote.contribution` import。
- [x] 删除 `src/vs/workbench/contrib/remote/` 目录。
- [x] 删除 `src-tauri/src/commands/remote.rs` 与 `commands/mod.rs` 中的模块声明。
- [x] `src-tauri/src/lib.rs` 删除 `RemoteManagerStore` 导入、`manage` 注册、退出清理与全部 `remote_*` 命令。
- [x] 从根 `Cargo.toml` 与 `src-tauri/Cargo.toml` 删除 `sidex-remote` 成员/依赖，删除 `crates/sidex-remote/`。
- [x] 删除远程相关快捷键、状态栏项与用户设置入口。
- [x] 评估 `remoteTunnel` / `tunnel` / `sidex-auth` 依赖链，保留架构必需的空实现。
- [x] 保留 `nullRemoteAgentService` 等架构空服务。
- [x] 清理 `RemoteExplorer`、`connectSSH`、`workbench.view.remote` 等用户入口；`remote_*` 仅存在于保留的兼容服务中。
