## 背景

`crates/sidex-settings` 原有多余 350+ 默认配置项，包含大量 IDE 功能（调试、任务、测试、笔记本、同步、远程、终端子特性等）。设置面板会暴露已不存在或不需要的选项。

## 实施结果

### 默认值清理（`crates/sidex-settings/src/defaults.rs`）

| 处理 | 内容 |
| --- | --- |
| 删除函数 | `add_debug_defaults`、`add_notebook_defaults`、`add_breadcrumb_defaults` 及其调用 |
| 删除键 | `extensions.supportUntrustedWorkspaces` |
| 更新键 | `extensions.autoUpdate`、`extensions.autoCheckUpdates` 改为 `false` |
| 默认关闭 | `editor.minimap.enabled`、`editor.parameterHints.enabled`、`editor.colorDecorators`、`editor.codeLens`、`editor.inlayHints.enabled`（`"off"`）、`editor.stickyScroll.enabled` |
| 保留分组 | 编辑器、工作台、文件、基础终端、搜索、窗口、资源管理器、扩展、输出、语言级覆盖 |

当前默认项 328 个，不再包含 debug、task、test、notebook、comment、chat、sync、remote、profile、marketplace 相关键。

### 设置面板分组（`settingsLayout.ts`）

设置目录已重写为五组：

| 分组 | 覆盖设置 |
| --- | --- |
| 文件与浏览 | `files.*`、`explorer.*`、`search.*`、`problems.*`、`output.*` |
| 编辑器 | `editor.*`、`diffEditor.*`、`terminal.*` |
| 主题与外观 | `workbench.*`、`window.*` |
| 键位 | `keyboard.*` |
| 扩展 | `extensions.*` |

`COMMONLY_USED_SETTINGS` 中的 `chat.agent.maxRequests` 已替换为 `explorer.confirmDelete`。

### 设置搜索标签（`settingsEditor2.ts`）

删除 `@tag:notebookLayout`、`@tag:notebookOutputLayout`、`@tag:sync` 及 `@feature:debug`、`@feature:task`、`@feature:comments`、`@feature:remote`、`@feature:notebook`、`@feature:chat` 建议。保留文件、搜索、扩展、终端、问题、输出、Telemetry、无障碍等与现有功能相关的标签。

### 前端默认覆盖（`src/main.ts`）

删除已无对应功能的 `chat.editor.enabled`、`chat.commandCenter.enabled` 覆盖项。
