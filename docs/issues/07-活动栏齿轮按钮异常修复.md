# 07 活动栏齿轮按钮异常修复

| 字段 | 内容 |
| --- | --- |
| Issue 编号 | SIDEX-TRIM-007 |
| 优先级 | P0 |
| 状态 | 已完成（2026-11-04） |
| 来源 | [功能裁剪复核](../file-manager-editor-spec.md) 5.2 / 5.3 P0 |
| 依赖 | SIDEX-TRIM-002、SIDEX-TRIM-006 |

## 背景

活动栏最后一个按钮的悬浮标题曾显示为「管理授权扩展 URI...」，不是「设置」或「管理」，用户点击后看到的菜单与标题不一致。

## 执行结果（2026-11-04）

| 项目 | 实际改动 |
| --- | --- |
| 图标 | `GlobalActivityActionViewItem` 固定使用齿轮图标 `DEFAULT_ICON`，不再读取 Profile 图标 |
| 标题 | 删除 `computeTitle` 中的 Profile 文案覆盖，按钮标题稳定为「设置/管理」 |
| 菜单项 | 删除 `ManageAuthorizedExtensionURIsAction`（`workbench.extensions.action.manageAuthorizedExtensionURIs`） |
| NLS 冲突 | `manage` key 不再被扩展 URL 授权命令覆盖，中文文案恢复正确 |

## 原始实施清单

- [x] 确认标题来源为 `GlobalActivityActionViewItem` 的 action 名称与 Profile 覆盖。
- [x] 将 action 名称固定为 `localize('manage', 'Manage')` / 中文「设置」。
- [x] 从 `MenuId.GlobalActivity` 移除扩展 URL 授权等无关菜单项。
- [x] 删除 `extensionUrlHandler.ts` 中的 `ManageAuthorizedExtensionURIsAction`。
- [x] Profile 图标不再影响按钮图标。
- [x] 菜单只包含设置、主题、键位等保留项。

## 验收结果

| 验收项 | 结果 |
| --- | --- |
| 活动栏末位按钮标题 | 「设置/管理」 |
| 菜单项 | 与裁剪后功能一致 |
| 命令面板「管理授权扩展 URI」 | 无结果 |
| `npx tsc --noEmit` / `npm run build` | 通过 |
