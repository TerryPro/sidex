## 背景

扩展市场面板已在阶段 0 移除，但命令面板仍残留「在市场浏览颜色主题」「检查扩展更新」等入口，与「只保留内置扩展和 Rust/WASM 扩展」的决策不一致。

## 执行结果（2026-11-04）

| 项目 | 实际改动 |
| --- | --- |
| 主题市场 | 删除 `browseColorThemesInMarketplace` 命令与菜单项 |
| 扩展更新入口 | `workbench.extensions.action.extensionUpdates` 保留代码，但依赖 `CONTEXT_HAS_GALLERY`；市场服务移除后该上下文为 false，命令与过滤菜单均不显示 |
| 扩展面板 | 只保留已安装、内置、Rust/WASM 扩展；市场、推荐、更新区块不注册 |
| 自动更新设置 | `extensions.autoUpdate`、`extensions.autoCheckUpdates` 默认 `false` |
| 市场服务 | `extensionGalleryService` 保留空实现供扩展服务构造，不暴露用户入口 |

## 原始实施清单

- [x] 删除 `browseColorThemesInMarketplace` 命令与菜单项。
- [x] 删除扩展更新动作的可见入口（受 `CONTEXT_HAS_GALLERY` 控制，市场移除后不可见）。
- [x] 清理扩展面板中与市场/推荐/更新相关的视图与欢迎内容。
- [x] `extensionGalleryManifestService` 保留空实现，避免扩展服务构造失败。
- [x] 扩展自动更新默认关闭。
- [x] 全仓搜索 `Marketplace`、`CheckForUpdates`、`extensionUpdates`、`gallery`，仅保留内部服务与未触发动作。

| 已安装扩展管理 | 查看、启用、禁用、卸载可用 |
