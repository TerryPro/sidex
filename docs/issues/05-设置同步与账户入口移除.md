# 05 设置同步与账户入口移除

| 字段 | 内容 |
| --- | --- |
| Issue 编号 | SIDEX-TRIM-005 |
| 优先级 | P1 |
| 状态 | 已完成（2026-11-04） |
| 来源 | [功能裁剪复核](../file-manager-editor-spec.md) 5.2 / 5.3 P0 |
| 依赖 | 无 |

## 背景

设置同步、账户登录、云数据清理属于 VS Code 账号体系，当前实现为 null 空服务，但命令面板仍能看到「清除云数据并停止同步」等命令，属于无意义入口。

## 执行结果（2026-11-04）

| 项目 | 实际改动 |
| --- | --- |
| 同步命令 | `CONFIGURE_SYNC_COMMAND_ID`、`SHOW_SYNC_LOG_COMMAND_ID` 仅保留常量，不再注册命令与菜单 |
| 设置页同步引导 | `settingsEditor2.ts` 的「Backup and Sync Settings」按钮由 null 服务控制，默认隐藏，不产生用户入口 |
| 账户入口 | 活动栏/标题栏账户按钮与账户菜单项已移除 |
| 状态栏 | 无同步/账户状态项 |
| 空服务 | `NullUserDataSyncWorkbenchService`、`nullUserDataSync` 保留，保证扩展管理服务可注入 |

## 原始实施清单

- [x] 删除 `CONFIGURE_SYNC_COMMAND_ID`、`SHOW_SYNC_LOG_COMMAND_ID` 等命令注册与菜单入口。
- [x] `settingsEditor2.ts` 同步引导按钮默认隐藏，不触发 `workbench.userDataSync.actions.turnOn`。
- [x] 删除账户活动栏/标题栏入口与账户菜单项。
- [x] 清理同步相关状态栏项与用户设置入口。
- [x] 保留 `NullUserDataSyncWorkbenchService`、`nullUserDataSync` 等空实现，确保扩展管理服务可注入。
- [x] 全仓搜索 `userDataSync`、`sync.actions`、`account`，仅保留内部空服务。

> 保留说明：`settingsEditor2.ts` 中同步横幅代码与 `userDataSync` 接口保留为空服务实现，运行时默认隐藏；不影响设置面板可见内容。

| 活动栏与标题栏账户按钮 | 已移除 |
| `npx tsc --noEmit` / `npm run build` | 通过 |
