# 11 自动更新裁剪

| 字段 | 内容 |
| --- | --- |
| Issue 编号 | SIDEX-TRIM-011 |
| 优先级 | P1 |
| 状态 | 已完成（2026-11-04，采用方案 A） |
| 来源 | [功能裁剪复核](../file-manager-editor-spec.md) 5.3 P1 |
| 依赖 | 无 |

## 背景

自动更新包含检查、下载、安装、重启与常驻轮询。产品不通过自动更新分发，因此整项删除，减少网络请求、Rust 依赖与设置项。

## 决策

采用**方案 A：删除自动更新**。版本更新由安装包分发。

## 执行结果（2026-11-04）

| 项目 | 实际改动 |
| --- | --- |
| 前端 UI | `src/vs/workbench/contrib/sidexUpdate/` 已删除，`workbench.web.main.ts` 移除 import |
| 更新服务 | `updateService` 保留为空实现，`_bootstrap` 直接进入 `Idle`，不发网络请求 |
| 菜单 | 移除标题栏/帮助菜单中的「Check for Updates…」入口 |
| Rust crate | `crates/sidex-update/` 已删除，Cargo 依赖清理 |
| Rust 命令 | `commands/updater.rs` 已删除，`lib.rs` 移除 `UpdateManagerState`、`initialize` 与 `update_*` 命令 |
| 设置 | `update.mode` 固定为 `none`，`update.showReleaseNotes` 为 `false` |
