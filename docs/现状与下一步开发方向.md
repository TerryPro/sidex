# SideX 现状与后续方向规范

> 更新时间：2026-11-05。基线：`4351b328` 之后的扩展体系收口改动（当前工作区）。本轮已验证类型检查、前端构建、Rust 检查与测试、启动冒烟；提交后以最新提交为准。

## 一、定位与边界

SideX 是「Windows 文件管理器 + 轻量编辑器」，不是专业 IDE。

| 保留 | 不做 |
| --- | --- |
| 目录标签、导航树、文件列表、地址栏 | LSP、补全、跳转、诊断、重构 |
| 文件操作、预览与属性、缩略图 | Git / SCM / 时间线 |
| Monaco 编辑、原生 CSV 表格、图片/PDF/HTML/Markdown 预览 | Node / WASM 扩展运行时、扩展市场 |
| 终端、搜索、大纲、折叠 | AI 聊天、多窗口、账号同步、遥测、自动更新 |
| 内置声明式扩展 | 系统级 Shell 扩展、默认文件关联 |

决策依据见 [ADR 0001：产品边界](adr/0001-产品边界.md)。

## 二、术语

规范术语以 [GLOSSARY.md](../GLOSSARY.md) 为准。最容易混用的概念：

| 使用 | 避免 |
| --- | --- |
| 目录标签 | 项目、工作区、Tab |
| 工作集 | 会话、打开文件列表 |
| 会话恢复 / 热退出 | 自动保存、崩溃恢复 |
| 预览与属性面板 | 预览器、属性栏 |
| 声明式扩展 | 插件、扩展包 |
| 内置扩展面板 | 扩展市场、扩展管理 |
| 虚拟滚动 | 分页、无限滚动 |

## 四、路线图与验收标准

### P0：收口当前重构（已完成，2026-11-05）

| 项 | 内容 |
| --- | --- |
| 目标 | 把扩展体系清理完成并稳定下来 |
| 结果 | 旧扩展管理视图、扩展诊断、bisect、市场/安装命令与 URL 安装链路已移除；扩展入口只剩只读的「内置扩展」面板；Node/WASM 扩展进程不再出现 |
| 验收 | `npx tsc --noEmit`、`npm run build`、`cargo check`、`cargo test --workspace` 通过；应用启动冒烟通过；无临时产物；文档与实现一致 |

### P1：会话恢复 + 虚拟滚动

| 项 | 内容 |
| --- | --- |
| 目标 | 重启恢复完整现场；万级目录可连续浏览 |
| 会话恢复 | 恢复目录标签、文件标签、活动文件、光标、滚动位置、导航历史；热退出保留未保存缓冲区，不弹保存对话框；文件被外部修改时提示 |
| 虚拟滚动 | 替换每页 300 行；排序与过滤作用于完整数据集；目录读取与 stat 分批异步；过期请求可取消 |
| 验收 | 重启后布局与编辑位置一致；脏缓冲区不丢失；10,000 项目录滚动不阻塞输入；选择与键盘导航稳定；快速切换目录不出现旧结果覆盖 |

### P2：文件操作安全 + 拖放

| 项 | 内容 |
| --- | --- |
| 目标 | 完成资源管理器式文件管理 |
| 文件操作 | 默认回收站删除；Shift+Delete 永久删除并确认；冲突提供替换/跳过/重命名；批量操作有进度与取消；保留最近 20 步撤销 |
| 拖放 | 应用内跨目录/跨标签移动与复制；Ctrl/Shift 调整语义；支持系统拖入与拖出 |
| 验收 | 常用操作可完成；删除可从回收站恢复；冲突可处理；撤销可回退；拖放移动/复制结果正确 |

### P3：精简与性能

| 项 | 内容 |
| --- | --- |
| 目标 | 去掉 IDE 残留，降低包体与维护面 |
| 精简 | 旧扩展管理视图、扩展诊断、bisect 已在 P0 完成；合并重复的平台命令；设置项按现有功能收敛；移除或重构无诊断来源的 Problems 面板 |
| 性能 | PDF、Mermaid、HTML 预览按需加载；拆分 `nls.js` 与 workbench 主包；大目录列表使用虚拟滚动 |
| 验收 | 扩展入口无重复；设置项数量下降；无死面板入口；最近一次构建 JS 17.32 MB（总 18.49 MB），P3 后目标 ≤ 16 MB；无新增 `dead_code` 警告 |

### P4：体验补齐

| 项 | 内容 |
| --- | --- |
| 目标 | 补齐常用文件管理器体验 |
| 图标与缩略图 | 保留文件图标主题（vscode-icons），不实现 Windows Shell 系统图标；图片、视频、PDF 生成异步缩略图并写入本地缓存 |
| 目录隔离 | 终端按目录标签惰性创建会话组，cwd 跟随标签；搜索范围跟随标签；侧边栏宽度按标签保存；底部面板布局全局共享 |
| 常用入口 | 最近目录、收藏夹、F2 重命名、Delete 删除、Ctrl+C/X/V、Enter/Backspace、Alt+Enter 属性 |
| 验收 | 主题图标显示正确；缓存缩略图即时显示且不阻塞滚动；终端/搜索/侧边栏随标签切换；快捷键与资源管理器一致 |

## 五、质量与验收基线

| 项 | 要求 |
| --- | --- |
| 类型与构建 | `npx tsc --noEmit`、`npm run build` 通过 |
| Rust | `cargo check` 通过；关键模块 `cargo test` 通过；无新增 `dead_code` |
| 测试 | `directoryService` 工作集与文件操作单测；Rust fs/search/syntax 测试；启动冒烟 |
| 大目录 | 10,000 项目录首屏可交互 ≤ 1 秒，连续滚动 ≥ 50fps（目标值，待实测校准） |
| 启动 | 冷启动 ≤ 2 秒（目标值，待实测校准） |
| 包体 | 以最近一次构建 JS 17.32 MB（总 18.49 MB）为上限；P3 后目标 ≤ 16 MB |
| 文档 | 状态表与代码一致；推翻 ADR 前先更新 ADR |

## 六、不做清单

| 方向 | 原因 |
| --- | --- |
| LSP、补全、诊断、格式化 | 与轻量文件管理器定位冲突 |
| Git / SCM / 时间线 | 已裁剪，不属于文件管理核心 |
| Node / WASM 扩展运行时、扩展市场 | 已裁剪，避免外部进程、市场与账号依赖 |
| 多窗口、系统级 Shell 扩展、默认文件关联 | 产品明确单窗口、自绘菜单 |
| AI 聊天、账号同步、遥测、自动更新 | 增加包体与网络依赖，偏离主线 |

## 八、历史裁剪摘要

已移除 Node 扩展宿主、WASM 扩展运行时、扩展市场、扩展诊断、bisect、Git/SCM、LSP、调试、任务、测试、笔记本、远程、AI 聊天、账号同步、遥测与自动更新。保留的能力集中在文件浏览、文件管理、预览、编辑与终端，目的是降低包体、启动时间和维护面，并避免产品重新滑向专业 IDE。
