# 文件列表采用虚拟滚动

Status: accepted（2026-11-05）

当前文件列表以每页 300 行的方式加载，翻页会打断选择与滚动，无法满足万级目录的浏览体验。我们决定改为虚拟滚动：只为可视区域及少量缓冲行渲染界面元素，排序与过滤作用于完整数据集；目录读取与 stat 分批异步执行，过期请求可取消。

## Consequences

- 需要稳定的行键、选择模型与键盘导航，列表组件复杂度上升。
- 分页加载退出文件列表，虚拟滚动成为唯一大目录策略。
- 必须补充万级目录的性能验收，滚动不得阻塞输入或明显掉帧。

## Considered Options

- 保留分页：实现简单，但不符合资源管理器式连续浏览。
- 一次性渲染全部行：实现最简单，但万级目录会卡顿。
