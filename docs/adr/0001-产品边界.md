# SideX 定位为文件管理器优先的轻量编辑器

Status: accepted（2026-11-05）

SideX 保留 VS Code workbench 外壳是为了获得熟悉的编辑体验，但产品核心是 Windows 文件浏览与文件管理。我们决定不再向专业 IDE 扩张：保留目录标签、文件列表、文件操作、预览、Monaco 编辑、原生 CSV 与终端；语言能力只保留关键字高亮、折叠和大纲，不引入 LSP、Git/SCM、扩展运行时、扩展市场、AI 聊天、多窗口、账号同步、遥测与自动更新。

## Consequences

- 新功能必须先回答：它是否改善文件浏览、文件管理或编辑体验；否则不做。
- 语言能力不追求补全、跳转、诊断、重构；包体、启动时间和维护面优先。
- 目录标签、工作集和文件列表是主线，编辑器和终端是配套能力。

## Considered Options

- 保留完整 IDE 能力：包体、进程与维护成本过高，且与产品定位冲突。
- 混合模式（文件管理器 + 可选 IDE 模式）：交互复杂，容易被 IDE 能力牵着走。
