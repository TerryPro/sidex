# 扩展体系只保留声明式扩展

Status: accepted（2026-11-05）

SideX 不再提供可执行扩展运行时。扩展只允许以声明式形式存在：TextMate 语法、主题、语言配置等静态贡献，由应用启动时扫描内置目录加载。界面只保留一个只读的「内置扩展」面板，旧扩展管理视图、扩展诊断、bisect、市场/安装命令与 Node/WASM 运行时全部移除；CSV 由原生表格编辑器处理。

## Consequences

- 第三方扩展无法再注入可执行代码，扩展相关的攻击面、启动开销与维护成本显著降低。
- 语言能力固定为内置高亮、折叠与大纲；不再依赖扩展补齐功能。
- 需要清理旧扩展视图、诊断命令与市场残留，避免出现重复入口或死代码。

## Considered Options

- 只保留 WASM 运行时：仍要维护宿主、权限与分发链路，收益不足以覆盖成本。
- 保留完整 Node 扩展宿主：与文件和编辑核心无关，且会重新引入外部进程与市场依赖。
