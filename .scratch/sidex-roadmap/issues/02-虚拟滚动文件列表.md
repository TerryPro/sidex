# 02: 虚拟滚动文件列表

**What to build:** 用虚拟滚动替换每页 300 行的分页；万级目录可连续滚动，排序与过滤作用于完整数据集；目录读取与 stat 分批异步，切换目录时过期请求可取消。

**Blocked by:** 01 收口扩展清理与绿色基线

**Status:** done

- [x] 10,000 项目录滚动不阻塞输入，无明显掉帧
- [x] 排序/过滤覆盖完整数据集，不只当前页
- [x] 快速切换目录不出现旧结果覆盖新目录
- [x] 选择、键盘导航、滚动位置在重绘后保持

## Comments

- 2026-11-05：实现虚拟滚动。文件列表按固定行高 `28px` 只渲染可视区 + 8 行缓冲，滚动时增量回收/复用行，DOM 行数恒定；排序、过滤改为基于缓存的完整数据集，排序与搜索不再重新读取目录；刷新、图标主题切换和标签切换均保留滚动位置；快速切换目录继续用 `requestId` 丢弃过期结果。
- 键盘与选择：列表改为 `role=listbox`，支持 ↑/↓/PageUp/PageDown/Home/End/Enter；选中项按路径保存，行回收后自动恢复；滚动停止 250ms 后才持久化位置，避免滚动中频繁写存储。
- 目录读取：`read_dir` 已由 Rust 在一次 IPC 中返回名称、大小与修改时间，前端不再逐行 stat；前端只对可视行做渲染，目录切换沿用请求序号丢弃过期结果。
- 验证：`npx tsc --noEmit`、`npm run build` 通过；应用启动冒烟通过。2026-11-06 使用 `F:\TRAEWS\sidex-10k-test`（10,000 文件）人工验证滚动、排序、搜索、选择保持、键盘导航与快速切换目录，均通过。
