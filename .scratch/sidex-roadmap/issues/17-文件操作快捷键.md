# 17: 文件操作快捷键

**What to build:** 文件列表支持 F2 重命名、Delete 回收站删除、Ctrl+C/X/V、Enter 打开、Backspace 向上、Alt+Enter 属性，与资源管理器一致。

**Blocked by:** 06 文件操作撤销栈

**Status:** done

- [x] 列表聚焦时快捷键生效且不与编辑器冲突
- [x] 多选时复制与删除作用于全部选中项
- [x] Alt+Enter 打开属性视图或对话框
- [x] 快捷键可被键位设置覆盖

## Comments

- 2026-11-06：新增 `fileListCommands.ts`，通过 `KeybindingsRegistry` 注册 F2、Delete、Shift+Delete、Ctrl+C/X/V、Enter、Backspace、Alt+Enter、Ctrl+Z、F5、Ctrl+A，`when` 限定为 `sidexFileListFocus`，仅在文件列表获得焦点时生效，不会抢占编辑器快捷键。文件列表支持 Ctrl 切换、Shift 连续、Ctrl+A 全选，复制/删除/属性均作用于全部选中项。默认规则注册到键位系统，可在键位设置中覆盖。
