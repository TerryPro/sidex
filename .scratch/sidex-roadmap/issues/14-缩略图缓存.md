# 14: 缩略图缓存

**What to build:** 图片、视频、PDF 在文件列表显示缩略图；首次生成不阻塞滚动，缓存命中即时显示；失败时回退文件图标主题。

**Blocked by:** 02 虚拟滚动文件列表

**Status:** done

- [x] 图片、视频、PDF 行显示缩略图
- [x] 缓存命中后再次进入目录不重复解码
- [x] 生成失败或超大文件回退主题图标
- [x] 万级目录滚动不被缩略图生成阻塞

## Comments

- 2026-11-06：新增 `thumbnailService`（`IThumbnailService` 单例），在文件列表行渲染后异步请求缩略图，成功后用 20px 图片替换主题图标，失败时保持原主题图标。仅对当前虚拟滚动可见行发起请求。
- 图片：`IFileService` 读取后经 `Image` 解码并绘制到 48×48 canvas，输出 PNG data URL；上限 32 MB。PDF：复用按需加载的 pdf.js 内核，渲染首页到 48×48 canvas；上限 64 MB。视频：通过 `sidex-asset` 协议加载，`loadedmetadata` 后 seek 到 1 秒内取帧；上限 512 MB，10 秒超时。
- 缓存：内存 Map（最多 300 条）+ IndexedDB `sidex-thumbnails`，键为小写路径，校验 `mtime + size` 后命中；写入超过 1000 条时按创建顺序裁剪到 700 条。缓存不可用时自动退化为内存缓存。
- 调度：`requestIdleCallback`（超时 1 秒）排队，最多 2 个并发，滚动和输入优先；行被回收后通过 `icon.isConnected` 丢弃结果。
- 资源协议：`sidex-asset` 增加 `Range` 支持（206 + Content-Range + Accept-Ranges），避免视频缩略图读取整个文件；补充视频/图片/PDF MIME。
- 验证：`npx tsc --noEmit`、`npm run build`（JS 17.26 MB，总 18.42 MB）通过；`cargo test --lib` 含 `Range` 解析测试 18 项通过；`npm run tauri dev` 启动冒烟通过。PDF 首页渲染使用 Edge 对构建产物实测，输出 48×48 有效像素；视频与图片缩略图建议在应用内人工快速确认。
