# 18: 设置项显式中文标题

**What to build:** 为设置编辑器中的核心设置提供显式中文标题，不再由设置键自动拆词生成英文；未覆盖的扩展贡献设置保留英文回退。

**Blocked by:** 10 设置项收敛（已完成）

**Status:** done

- [x] 文件与浏览、编辑器、主题与外观、键位五组内的核心设置标题显示中文
- [x] 标题改造不影响按设置键搜索与跳转（如 `files.autoSave` 仍可命中）
- [x] 未覆盖的扩展贡献设置回退为现有英文标题，不出现空白
- [x] 记录中文标题覆盖数量（221 / 221 个默认项）
- [x] `npx tsc --noEmit` 与 `npm run build` 通过

## Comments

- 2026-11-06：新增 `settingsTitles` 映射（`sidexSettingTitles.ts`），覆盖 `crates/sidex-settings/src/defaults.rs` 的全部 221 个默认键，其中 208 个核心设置使用中文标题，13 个语言覆盖键保留 `$(bracket) 语言名` 形式。`settingsTreeModels.ts` 的 `initLabels()` 在 `ISetting.title` 为空时优先查映射，未命中的扩展设置仍回退 `settingKeyToDisplayFormat` 的英文标题。搜索仍基于设置键与描述，`files.autoSave` 等键可正常命中。

## 实现提示

- 当前标题由 `settingKeyToDisplayFormat` 按 key 拆词生成（`src/vs/workbench/contrib/preferences/browser/settingsTreeModels.ts`）；`ISetting.title` 在 `preferencesModels.ts` 构造设置时未赋值，所以始终走英文自动标题。
- 建议新增集中式「设置 key → 中文标题」映射（例如 `src/vs/workbench/contrib/preferences/common/settingsTitles.zh-cn.ts`），在构造 `ISetting` 时写入 `title`，避免逐条修改配置注册；仅在 zh-cn 语言下启用。
- 标题文案以 `crates/sidex-settings/src/defaults.rs` 的 221 个默认项为最小覆盖集合，再按五个分组补全剩余核心设置。
- 搜索使用 key 与描述，不依赖标题；需回归确认搜索命中、排序与分组不变。
