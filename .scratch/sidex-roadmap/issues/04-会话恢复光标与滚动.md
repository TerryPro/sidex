# 04: 会话恢复：光标、滚动与列表位置

**What to build:** 在基础会话恢复之上，重启后恢复每个文件的光标、编辑器滚动位置与文件列表滚动位置；与虚拟滚动协同工作。

**Blocked by:** 02 虚拟滚动文件列表、03 会话恢复：目录标签、文件标签与导航历史

**Status:** done

- [x] 活动文件光标位置恢复
- [x] 编辑器滚动位置恢复
- [x] 文件列表滚动位置恢复，虚拟列表不跳动
- [x] 切换目录标签时各自位置互不覆盖

## Comments

- 2026-11-06：每个目录标签保存活动编辑器的 `viewState`（光标、选择、折叠与滚动），来源为 `IEditorService.activeEditorPane.getViewState()`；切换标签或退出时写入工作集，恢复标签时通过 `editorService.openEditor(..., { viewState })` 交回文本编辑器。
- 工作集切换前先捕获当前标签活动编辑器状态，再关闭编辑器，避免关闭时清空 view state。
- 文件列表滚动沿用已有的 `sidex.directory.scroll:<tabId>`：目录视图切换、编辑器遮挡恢复和重启都按标签恢复；恢复后调用 `virtualList.update()` 重算可视行，避免虚拟列表跳动。
- 验证：`npx tsc --noEmit`、`npm run build` 通过。通过 WebView2 远程调试实际重启应用：GLOSSARY.md 活动光标恢复到第 7 行第 4 列，编辑器滚动恢复到 scrollTop 90，文件列表标签与编辑器标签顺序一致。
