# 19: 文件列表查看模式与排序

**What to build:** 参考 Windows 资源管理器，为文件列表增加「详细信息 / 列表 / 图标」三档查看模式，并把排序从全局单键改为每个目录标签独立。

**Blocked by:** 无

**Status:** done

- [x] 右键空白区域提供「查看」子菜单，可在详细信息、列表、图标之间切换
- [x] 标题栏地址栏左侧增加「查看」「排序」按钮，点击展开下拉列表
- [x] 右键提供「排序方式」子菜单（名称/修改日期/类型/大小）与升序/降序
- [x] 列头点击仍可排序，并显示当前排序键与方向
- [x] 排序与查看模式按目录标签分别保存，新标签继承最近一次状态
- [x] 图标模式为固定尺寸网格卡片，列数随宽度自适应，键盘上下按整行、左右按单项移动
- [x] 「显示文件扩展名」开关只影响名称显示
- [x] 旧键 `sidex.directory.sort` 作为首次升级的回退
- [x] 新增 `fileListView` 纯函数与单测；`npx tsc --noEmit` 通过

## Comments

- 2026-11-08：新增 `common/fileListView.ts`（查看模式、视图状态归一化、扩展名显示），排序与查看状态改为 `sidex.directory.viewStates`（按标签）+ `sidex.directory.viewDefaults`（默认值），扩展名为 `sidex.directory.showExtensions`。`VirtualFileList` 支持网格排布；右键菜单支持二级子菜单。决策记录见 ADR 0004。
- 2026-11-08：状态收敛到 `FileListViewService` 单例，标题栏「查看 / 排序」按钮与文件列表编辑器共用同一份状态；点击按钮在下方展开下拉列表。
- 2026-11-08：菜单勾选改为固定宽度图标槽；升序/降序改为带箭头的分段按钮；标题栏「查看 / 排序」改用自绘 SVG 图标并加下拉箭头；新增一个方向切换按钮，单击直接翻转升降序。
