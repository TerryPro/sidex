# 09: 系统拖入/拖出

**What to build:** 支持从 Windows 资源管理器拖入 SideX，也支持从 SideX 拖出到资源管理器；复制/移动语义与系统一致。

**Blocked by:** 08 应用内拖放

**Status:** done

- [x] 系统拖入后文件出现在目标目录
- [x] 从 SideX 拖出后目标应用收到正确文件
- [x] 复制/移动修饰键行为正确
- [x] 失败时有提示且不留下半完成状态

## Comments

- 2026-11-06：拖入通过 Tauri `onDragDropEvent` 接入，按屏幕坐标命中文件夹行、目录标签或文件列表；修饰键由 Rust `get_modifier_keys` 读取，Ctrl 复制、Shift 移动，默认同盘移动/跨盘复制。拖出使用 Chromium 的 `DownloadURL` 格式配合 `sidex-asset` 协议，只能携带单个文件，目录与多选仅支持应用内拖放；该路径依赖 WebView2 的下载式拖出，需在真实桌面上手动验证。`copy_path` / `move_path` 在复制失败时清理本次新建的不完整目标，源文件保持不变，失败项汇总提示。
