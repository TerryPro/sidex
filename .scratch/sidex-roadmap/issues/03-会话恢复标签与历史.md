- 2026-11-06：目录标签、顺序、活动标签与每标签导航历史原本已由 `directoryService` 持久化到 `sidex.directory.tabs`，本次补齐编辑器工作集的跨重启持久化。

- 启动时不再关闭 VS Code 已恢复的编辑器，而是把它们作为当前目录标签的工作集；没有实时编辑器时从持久化工作集重建文件标签与活动文件。文件列表固定在标签首位。
