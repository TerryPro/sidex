# 清理 SideX 后端命令面（架构候选 C4）

## Context

`src-tauri/src/lib.rs` 的 `generate_handler!` 注册了 108 条 Tauri 命令，逐一核对 `src/**/*.{ts,js,html}` 与根 `index.html` 的字符串字面量后，有 44 条没有任何前端调用；其中 `crypto`、`path`、`text`、`editor` 四个模块的所有命令全死。这些死命令与 `commands/mod.rs` 的 `pub use x::*` 桶一起，使后端对外契约不可读、依赖无法回收。

目标：把后端命令面收敛到真实可达的 64 条，注册表改为模块限定路径，移除只为死代码存在的 crate 依赖，并加一条单向守卫测试防止再次长出死命令。

已确认的决策：
- 整模块删除 `crypto.rs`、`path.rs`、`text.rs`、`editor.rs`。
- 移除 `sidex-text` 依赖；删除 `sidex-workspace` 的 `path_util` 模块。
- 注册表改为 `commands::fs::read_file` 形式，删除 `pub use` 桶。
- 新增单向测试：注册 ⇒ 前端有字面量引用。
- `sidexRemoteService.ts` 本轮**跳过删除**（它被 `nullRemoteAgentService.ts` 使用），`workbench.common.main.ts:17` 保持不变。
- `log_frontend_error` 保留（根 `index.html:56` 有引用）。

## 改动清单

### 1. 整文件删除（4 个模块）
- `src-tauri/src/commands/crypto.rs`
- `src-tauri/src/commands/path.rs`
- `src-tauri/src/commands/text.rs`
- `src-tauri/src/commands/editor.rs`

### 2. `src-tauri/src/commands/mod.rs`
删除上述 4 个 `pub mod` 与对应的 4 行 `pub use ...::*;`；其余 `pub mod` 保留，`validation` 保持注释状态。

### 3. 逐函数删除（39 条命令）
| 文件 | 删除内容 |
| --- | --- |
| `commands/fs.rs` | `get_cwd` |
| `commands/terminal.rs` | `get_shell_integration_dir`、`setup_zsh_dotdir` |
| `commands/storage.rs` | `storage_get` |
| `commands/settings.rs` | `settings_load`、`settings_parse_jsonc`、`settings_modify_jsonc` |
| `commands/proxy.rs` | `proxy_request`（`validate_url`/`get_client`/`read_body_limited` 若仍被 `proxy_request_full` 使用则保留，否则一并删除） |
| `commands/watch.rs` | `watch_update_patterns`、`watch_list`、`watch_is_active`（`build_ignore_globset` 仍被 `watch_start` 使用，保留） |
| `commands/keymap.rs` | `keymap_resolve`、`keymap_resolve_chord`；随之删除仅被二者使用的 `context_from_map`、`HashMap`、`Value`、`parse_keybinding_string`、`ContextKeys`、`ContextValue` 导入 |

删除后若出现新的未使用导入/helper，一并清理（不留 `#[allow(dead_code)]`）。

### 4. `src-tauri/src/lib.rs`
- `generate_handler!` 内 64 条改为模块限定路径，例如 `commands::fs::read_file`、`commands::terminal::terminal_spawn`、`commands::settings::settings_get`。
- 删除已移除命令的注册行与对应分组注释。
- 顶部 `use commands::settings::SettingsStore;` 等已有模块路径保持不变。

### 5. 依赖清理
- `src-tauri/Cargo.toml`：删除 `sidex-text = { path = "../crates/sidex-text" }`。
- `crates/sidex-workspace/src/lib.rs`：删除 `pub mod path_util;` 与 `pub use path_util::PathInfo;`。
- 删除 `crates/sidex-workspace/src/path_util.rs`。
- `crates/sidex-text` 目录保留（归 C6 处理）。

### 6. 防回归测试
新增 `src-tauri/tests/command_surface.rs`：
- 从 `env!("CARGO_MANIFEST_DIR")/src/lib.rs` 解析 `generate_handler!` 中的命令名（正则 `^\s*commands::[\w:]*(\w+),$`）。
- 递归扫描 `../src` 下 `.ts/.js/.html` 及根 `index.html`（跳过 `node_modules`），拼接后检查命令名是否以 `'name'`、`"name"` 或 `` `name` `` 出现。
- 断言全部注册命令均被引用；失败时输出缺失命令名列表。

### 7. 明确不做
- 不删 `sidexRemoteService.ts`，不改 `workbench.common.main.ts`。
- 不动 VS Code 自带的 `IRemoteAgentService`/`NullRemoteAgentService`。
- 不做 UI 自动化。
