# 移除调试与测试功能 — 实施方案

## Context

用户在做"精简为纯文件浏览/编辑环境"的第二阶段，要求删除**调试**（contrib/debug，约 3.9 万行）和**测试**（contrib/testing，约 2.1 万行）两个子系统。已确认：扩展宿主的 `vscode.debug` / `vscode.tests` API 桥接一并删除；断点 gutter、右键菜单、Debug Console 入口等 UI 全部清干净。

保留：终端、任务（Run Task）、Git/SCM、问题面板、扩展管理、更新。

目标：删除后 `npx tsc --noEmit`、`cargo check --workspace`、`npm run build` 全部通过；启动后界面上没有调试/测试痕迹，其余功能不受影响。

## 范围边界

| 处理 | 内容 |
|---|---|
| 删除 | `contrib/debug/`、`contrib/testing/`、`platform/debug/`、`platform/sidex/browser/sidexDapService.ts` |
| 删除 | `workbench/api` 里的 debug/test 桥接（mainThreadDebugService、mainThreadTesting、extHostDebugService、extHostTesting、extHostTestingPrivateApi、extHostTestItem、tauri/extHostDebugService） |
| 删除 | Rust `commands/debug.rs`、`crates/sidex-dap`、相关命令注册 |
| 删除 | `src-tauri/extension-host/host.cjs` 里的 `debug` / `tests` 命名空间（纯本地 stub，无 RPC，`node --check` 可验证） |
| **不动** | `crates/sidex-extension-api` 的 `debug_api.rs` / `test_api.rs` 与 `world.wit`、`extensions-rust` 示例：它们是 WASM 扩展的独立内存 stub，不调用被删的任何代码；删它们要连带改 WIT 和 6 个示例 crate，收益低风险高（后续可单独处理） |
| 不动 | `$extensionTestsExecute` / `--extensionTestsPath`（这是"运行扩展自身的集成测试"，不是 Test Explorer） |

## 验证

1. 残留门禁（应为 0）：
   ```
   rg -n "contrib/(debug|testing)|platform/debug|IDebugService|IExtHostDebugService|IExtHostTesting|sidex-dap|sidexDapService" src src-tauri crates
   rg -n "vscode\.(debug|tests)" src-tauri/extension-host/host.cjs
   ```
   `cid` 与品牌词不受影响。
2. `npx tsc --noEmit` → `npx eslint`（改动文件）→ `npm run build`。
3. `cargo check --workspace`（此时**不需要** `AWS_LC_SYS_PREBUILT_NASM`）。
4. `node --check src-tauri/extension-host/host.cjs`。
5. `npx tauri dev` 启动并截图确认：
   - 活动栏无"运行和调试"图标；标题栏/菜单无 Run and Debug、Debug Console；F9 无效；编辑器左侧无断点 gutter；命令面板无 `Debug: Start`；侧边栏无 Testing 视图。
   - 保留项正常：资源管理器、搜索、Git、终端、任务、问题、设置、扩展面板。
6. 重启一次确认布局与状态记忆正常。

## 风险

- **运行期 DI 崩溃**：`viewQuickAccess`、`tauriExtensionHost` 等在构造器注入 `IDebugService`，必须先删注册再删实现，或同一次改动完成。
- **RPC 键不同步**：`@extHostNamedCustomer` 与 `MainContext` 键必须一起删，否则扩展宿主启动时注册失败。
- **host.cjs 语法**：手写 CommonJS，删块后必须 `node --check`；若失败立即回滚该文件。
- **孤儿文件**：`api/tauri/extHostDebugService.ts` 目前无 import，但仍在 tsc include 范围内，必须物理删除。
- 若中途 `tsc` 报出大量错误，按"入口 → api → 消费者 → 目录"的顺序回退，不要反向补空实现。
